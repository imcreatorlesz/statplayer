# Звёздный плеер

Папка целиком (index.html, sw.js, manifest.webmanifest, иконки) выкладывается как статический сайт. Нужен именно HTTPS, иначе не заработают установка и офлайн.

## Как выложить (любой из вариантов, бесплатно)
- **Netlify Drop**: откройте app.netlify.com/drop и перетащите папку (или zip). Ссылка готова сразу.
- **GitHub Pages**: создайте репозиторий, загрузите файлы, в Settings → Pages выберите ветку main.
- **Cloudflare Pages**: Create project → Direct Upload → загрузите папку.

## Обновления
При каждом изменении поднимайте номер версии в `sw.js` (`starplayer-1.0.0`) и `VER` в index.html, иначе у людей останется старая копия.

## Приватность и шрифты
Плеер ничего не отправляет, кроме загрузки шрифтов Manrope и Unbounded с Google Fonts. Если нужна полная приватность (например, строгий GDPR), скачайте эти шрифты, положите рядом, подключите через @font-face и уберите ссылку fonts.googleapis.com из index.html. Тогда поправьте строку про Google Fonts в окне «О плеере».

## Перед выпуском проверьте
Chrome, Samsung Internet, Safari (iPhone), Firefox. На iPhone громкость и плавный переход скрыты намеренно: Safari не даёт менять громкость из кода. Проверьте фоновое воспроизведение при заблокированном экране и копию на большой библиотеке.
